# 模型排班 · Model shift

按「星期 + 时段」规则自动切换 DeepSeek Harness 的默认模型：白天用官方模型保体感，夜间切到本地部署的免费模型。

## 能力

- **规则表**：每条规则 = 名称 + 星期 + 若干时段 + provider/model（可选 reasoningEffort）+ 备用模型。按顺序匹配，第一条命中的生效；都不命中用第一条启用的规则。结束时间早于开始时间表示跨午夜。
- **时段首尾衔接**（默认开启）：后一条规则的开始时间自动等于前一条的结束时间，避免规则之间出现空档；改前一条结束时后一条自动跟随，也可点「对齐时段」批量处理，或在开关处关闭。
- **两处一起切**：新会话（含恢复的会话）在 `agent/created` 时直接采用当前档位；已打开的会话写入模型选择，下一轮请求生效。**不写 profile 的 `agent-default-model` 行**，卸载后配置保持原样。
- **切前探活**：先向宿主 `llm` 服务解析目标模型；不可用时按规则里的备用模型依次尝试，全部失败就保持原模型不动，并在面板里写明原因。
- **上下文窗口守卫**：目标模型窗口小于会话当前上下文（超过 90%）时，该会话不切，其余照切。
- **手动选择的优先级**：在 DSH 界面手动改模型 → 本档内保留，跨档自动切回排班；在插件面板点「仅本会话使用」→ 视为显式钉住，跨档也保留（直到你再改模型或重载插件）。
- **可见性**：输入框右侧显示当前档位徽标，**点击**弹出快捷面板：选 provider/model 后可以「仅本会话使用」（切当前会话并本档内钉住）或「写入当前档位」（改规则并立即应用），也能暂停/恢复自动切换；完整时段规则在设置页「模型排班」。

## 使用

1. 打开 **设置 → 模型排班**。
2. 默认给了两条规则（08:00–23:00 官方 `deepseek-account/deepseek-flash`；23:00–08:00 本地 `wxb-models/dsv4flash`），按需改成自己的 provider/model 与时段。
3. 点 **保存并应用**；之后到点自动切换。需要立刻对齐时点 **立即切换**。

## 配置存放

排班文档在 `$DSH_HOME/plugins/model-shift/schedule.json`，由面板写入；宿主逻辑每秒巡检一次（间隔可在面板改，默认 20 秒）。

## 边界与限制

- 插件不改写 profile 的 `agent-default-model`：面板里显示的默认模型是**手动改过之前**的部署默认，实际生效值以排班为准；需要新会话跟着排班走就保持插件启用。
- 只切换主会话；子代理跟随父会话，不单独切换。
- 探活只验证路由与模型元数据能否解析，不代表上游此刻一定不 429。
- 与其它同样改写默认模型的插件（如 dsh-model-scheduler）同时启用会互相覆盖，只应保留一个。
